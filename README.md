# LSTM Movie Review Sentiment Analyzer

Predict whether a movie review is **Positive** or **Negative** using an LSTM neural network
(Python, TensorFlow/Keras, NumPy, Pandas, Matplotlib, Scikit-learn).

---
## Step 1 - Understand the assignment

**Objective (simple English).** Teach a computer to read a movie review and decide if the writer
liked the film. We show it 25,000 reviews that humans already labelled, it learns patterns, and
then we test it on 25,000 other reviews it has never seen.

**Sentiment analysis** = automatically finding the feeling (positive / negative / neutral) in text.

**Neural network** = layers of simple maths units. Each layer transforms its input; training adjusts the
numbers (weights) so that the final output matches the correct label more often.

**LSTM (Long Short-Term Memory)** = a neural network that reads a sequence one step at a time
(here, one word at a time) and keeps a *memory* of what it has read. Inside each LSTM cell, "gates"
decide what to forget, what to store and what to output.

**Why LSTM for text?**
- Word order matters: "not good" and "good" mean opposite things.
- Reviews have different lengths; an LSTM can process any sequence length.
- Earlier words can affect the meaning of later words ("The start was slow, *but* the ending was superb").
  Plain RNNs forget over long texts; LSTM gates help it keep important information.

**Requirements**
- Python + TensorFlow/Keras LSTM classifier, Positive/Negative output
- Data preparation: tokenizing, padding, train/validation/test split
- Training with validation, plots of accuracy and loss
- Evaluation: accuracy, precision, recall, F1, confusion matrix
- A way to predict new reviews
- Organized project, README, instructions that others can follow

**Expected deliverables:** the project folder (ZIP), README, trained model files and result plots
generated by *your* run, and (probably) a short report. Check your assignment sheet for the exact list.

## Step 2 - Set up VS Code on Windows 11

Open the folder in VS Code (File > Open Folder), then open a terminal (Terminal > New Terminal).
Make sure it is **PowerShell**.

| # | Command | What it does |
|---|---|---|
| 1 | `python --version` | Shows your Python version. Use **3.10, 3.11 or 3.12**. |
| 2 | `pip --version` | Confirms pip (the package installer) exists. |
| 3 | `python -m venv .venv` | Creates a private environment in the `.venv` folder. |
| 4 | `.\.venv\Scripts\Activate.ps1` | Activates it; the prompt starts with `(.venv)`. |
| 5 | `python -m pip install --upgrade pip` | Updates pip. |
| 6 | `pip install -r requirements.txt` | Installs TensorFlow and the other libraries (large download, several minutes). |
| 7 | `python -c "import tensorflow as tf; print(tf.__version__)"` | Checks TensorFlow works. |

In VS Code press `Ctrl+Shift+P`, choose **Python: Select Interpreter**, and pick the one inside `.venv`.

If `python` is not recognized, install Python from python.org and tick **Add python.exe to PATH**,
then reopen VS Code.

### Troubleshooting
| Problem | Fix |
|---|---|
| `Activate.ps1 cannot be loaded... running scripts is disabled` | Run once: `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`, then activate again |
| `No matching distribution found for tensorflow` | Your Python is too new/old (or 32-bit). Install 64-bit Python 3.10-3.12 and recreate `.venv` |
| `pip` not found | Use `python -m pip ...` |
| `ModuleNotFoundError` | The venv is not active, or step 6 did not finish. Activate and rerun step 6 |
| Long-path / install error | Enable long paths in Windows, or move the project to a short path such as `C:\projects\` |
| DLL load failed when importing TensorFlow | Install the Microsoft Visual C++ Redistributable (x64) and restart |
| Messages about oneDNN or CPU instructions | Informational, not errors |
| Download of IMDB data fails | Check internet/VPN/proxy; the first run needs to download about 20 MB |

Note: native Windows TensorFlow runs on the **CPU** (GPU support ended after TF 2.10). This model is small
enough for a CPU, but training takes some minutes.

## How the model works
1. **Data:** Keras IMDB dataset, 25,000 training and 25,000 test reviews, labels 0/1.
2. **Preprocessing:** keep the 10,000 most frequent words; every review is cut or padded to 200 words.
3. **Model:** `Embedding(10000, 64)` -> `LSTM(64)` -> `Dropout` -> `Dense(32, ReLU)` -> `Dense(1, sigmoid)`.
   Output above 0.5 means Positive.
4. **Training:** Adam optimizer, binary cross-entropy, 20% of training data for validation, early stopping.
5. **Evaluation:** on the untouched test set.
6. **New text:** converted with the same dictionary (`encode_text`) so it matches the training format.

All settings (vocabulary size, review length, LSTM units, epochs) are in `src/config.py`.

## Limitations and ideas
- Only the first 200 words of each review are used.
- Trained on English IMDB reviews; sarcasm and other domains (e.g. product reviews) may fail.
- Words outside the 10,000-word vocabulary become "unknown".
- Ideas: Bidirectional LSTM, GloVe embeddings, hyperparameter tuning, a Streamlit web interface.
